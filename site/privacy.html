Privacy Policy

Effective: June 2026

Grab Anything does not collect, store, transmit, or sell any user data. Period.

  • No analytics, no telemetry, no tracking. The extension contains no analytics code and makes no network requests to any server operated by us.
  • All processing is local. Asset detection, the media list in the popup, and downloads all happen entirely on your device.
  • Settings are stored in Chrome's extension sync storage, managed by your own browser profile and never visible to us.
  • The per-tab media list is kept in Chrome's session storage and deleted automatically when the tab navigates or closes, or when the browser exits.
  • Network observation (the webRequest permission) is used only to note the URLs and types of media files a page loads, so the popup can list them for you. Requests are never modified, blocked, or reported anywhere.
