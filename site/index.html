What it grabs

Stuff browsers
make annoying.

Grab Anything is a free image, font and video downloader for Chrome. One right-click for the things that normally take dev tools and twenty minutes.

Images at full quality

Thumbnails get auto-upgraded to the CDN original: YouTube avatars, video stills, WordPress, Twitter. WebP saves as PNG automatically.

Logos as crisp SVG

Most site logos are inline SVG that browsers give you no way to save. One right-click, including a copy that pastes straight into Figma.

The fonts a page uses

Right-click any text and download the actual font file. Google Fonts, self-hosted, variable fonts, all of it.

Whole designs

Save a navbar, hero or footer as a working HTML+CSS file with hover states, media queries and fonts included. Or copy it, styles inlined.

Video & audio

Real media files, alternate encodings, subtitles, posters. Plus a popup gallery of every file the page loaded, so you can ZIP it all in one click.

Palette & font cards

One click exports a site's color palette and type specimen as shareable cards. Moodboards in seconds.

FAQ

Fair questions.

Is it safe?

Everything runs locally in your browser. No server, no account, and no analytics. The privacy policy is two minutes long because there's nothing to disclose: no data is collected, full stop. The permission list is explained in plain English above.

Is it really free? What's the catch?

Free, no trial, no locked features, no ads. It's an indie project; if it ever grows paid extras, the things on this page stay free.

Does it work on every website?

It works anywhere Chrome lets extensions run, which is almost everywhere except the Chrome Web Store itself and browser settings pages. Protected video streams (YouTube, Netflix) can't be saved: the video is assembled in memory from encrypted pieces, so there's no file to download. That's a browser-wide rule, not a missing feature.

Is downloading this stuff legal?

Saving things for personal use (study, reference, moodboards) is generally fine. Re-publishing someone's images, fonts or designs as your own isn't: assets stay licensed by their creators. Grab Anything gives you the file; the rights stay where they were.

When is it on Edge and Firefox?

Right after Chrome. The Edge version is the same build, and a Firefox port is ready and in testing. This page will link both the day they're live.

What does "full quality" actually mean?

Sites usually display a shrunken copy of an image while the original sits on their CDN. Grab Anything rewrites the image URL to request the original (it knows the patterns for YouTube, Twitter, Wikipedia, WordPress and more), checks it exists, and downloads that instead of the thumbnail.
